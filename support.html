Setting up

  1. Download Guard Lock for Mac, open the zip, drag Guard Lock into Applications and open it.
  2. Install the free Guard Lock iPhone app.
  3. On the Mac, click Pair iPhone App…, then scan the code it shows with the iPhone.
  4. Click Send Test Alert on the Mac. It should pop up on your iPhone within a few seconds.

When something's off

No alerts are coming through.

Both devices need to be signed in to the same Apple Account with iCloud Drive on. Notifications for Guard Lock have to be allowed on the iPhone (Settings › Notifications › Guard Lock), and the Mac's window should say "Alerts are on".

Wrong-password alerts come without a photo.

Turn on Photo on wrong password in the Mac window, and allow camera access when macOS asks for it.

Lock Mac is slow, or does nothing.

Allow notifications for Guard Lock on the Mac too (System Settings › Notifications › Guard Lock). That's how it gets the command right away.

I got a new Mac.

On the old one, open License in the Guard Lock window and click Deactivate License…. Then enter the same key on the new Mac.
